# pitstop 0.5.3 · release notes

- **Report:** one gap per resumed cycle; T3 delegate sessions on their own `sessions:` line.
- **Offer:** skipped when no work is left (the hard request is unchanged).
- **R-MARK (T1):** `--reply-checked` no longer skips the owed-reply check. A subagent report or an ended delegate
  counts as an event, like a user message, and the refusal names it. The `/pitstop` command itself does not.
- **Waggle ids (T2):** mark-pending refuses a case id that is not `c_` plus a full uuid.
- **Done work (T3):** new skip category `done`; mark-pending refuses an empty Next action ("—", "Nothing
  pending", "Nessuna"). A sub-agent writes its final report instead of a skip line.
- **Delegates (F4):** a T3 delegate's resume message asks for no banner, so its parent gets the report.
- **Language (T4):** the resume message names the reply language found under User preferences. Rules on code
  or commits, negated rules and "when I write X" rules are ignored.
- **Checkpoint content (R1, R2):** exact paths or commands for every script, draft or data the work made; the
  approved mockup with its Waggle case id and the feedback ledger with its open ids.
